Everything you need, nothing you don't

PaperNexus works quietly in your system tray, keeping your desktop fresh without getting in the way.

🌐

Multiple Wallpaper Sources

Ships with Bing Daily and Spotlight 4K feeds. Add any custom HTTP JSON source with configurable JPath expressions.

⏰

Flexible Scheduling

Simple intervals from seconds to years, or full cron expressions for fine-grained control. Each source gets its own schedule.

🖼

Gallery View

Browse your wallpaper collection visually. Set any wallpaper as current, mark favorites, or ban the ones you don't like.

❤

Favorites & Bans

Heart wallpapers to boost their priority in rotation. Ban wallpapers to permanently exclude them. You're in control.

🎨

Title Annotations

Optional text overlay showing the wallpaper title with auto-contrasting outline. Customizable font, size, position, and color.

🔄

Silent Auto-Updates

Checks GitHub Releases in the background and updates itself seamlessly. Includes automatic rollback if anything goes wrong.

Up and running in seconds

No installers, no configuration wizards, no nonsense.

1

Download

Grab the latest PaperNexus.exe from GitHub Releases. It's a single file — no installation needed.

2

Run it

Double-click the exe. PaperNexus sets itself up, parks in your system tray, and starts fetching wallpapers immediately.

3

Enjoy

That's it. Your desktop now rotates through stunning wallpapers on autopilot. Go get a coffee.

Lives in your system tray

PaperNexus stays out of your way, running silently in the background. Right-click the tray icon whenever you want to take control.
